# 0012. Original personas only

- Status: Accepted
- Date: 2026-11-24

## Context
Character names and voices made to imitate real actors carry trademark and right-of-publicity risk, even when the voice was generated from a prompt.

## Decision
The repo ships only **original** personas: Ashford, Klaus, Pettigrew, and Lucy. Users can build personal packs locally with the provided tools; the project won't distribute imitations. Persona style applies to spoken and chat replies only.

## Consequences
Less fan appeal out of the box; a much safer project.
