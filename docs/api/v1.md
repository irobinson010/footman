# Footman local API v1

**Experimental until Footman 1.0** (ADR-0018). Methods and payloads may still change; changes are recorded in ADRs.

The daemon (`footman daemon`) serves JSON-RPC 2.0 to local clients. The `footman` CLI commands `status`, `say`, `stop` and `events` are clients of this API; anything they do, another client can do. Wire details are in ADR-0025.

## Connecting

- **Socket:** `$XDG_RUNTIME_DIR/footman.sock` on Linux (`/tmp/footman-<uid>/footman.sock` when `$XDG_RUNTIME_DIR` is unset). `footman status` prints the path in use; `$FOOTMAN_SOCKET` overrides it for the daemon and the CLI. The path must fit the OS's socket address: at most 107 bytes on Linux and 103 on macOS and the BSDs. The daemon refuses a longer path before it starts, and says how long it is and what the limit is.
- **Access:** the socket is `0600` and its directory `0700`, so only the user who runs the daemon can connect. There is no other authentication on the socket.
- **Framing:** one JSON value per line, ending in `\n`, in both directions. A line may hold a request, a notification or a batch array. Lines over 1 MiB close the connection.
- **Order:** requests on one connection run concurrently; match responses by `id`.

Try it by hand:

```sh
echo '{"jsonrpc":"2.0","id":1,"method":"status.get"}' | socat - UNIX-CONNECT:$XDG_RUNTIME_DIR/footman.sock
```

## Errors

Errors use the JSON-RPC `error` object. Codes:

| Code | Meaning |
|---|---|
| -32700 | Parse error: the line is not JSON |
| -32600 | Invalid request |
| -32601 | Method not found |
| -32602 | Invalid params (including unknown members) |
| -32603 | Internal error |
| -32000 | The method ran and failed; `message` says why |
| -32001 | Busy: another utterance is being handled |
| -32002 | Not found: no such job, subscription or config key |
| -32003 | Unavailable in this daemon |

## Methods

### `status.get`

No params. Result:

```json
{"version":"0.1.0","api":"v1","pid":4242,"started_at":"2026-11-25T09:00:00Z","uptime_seconds":90.5,
 "state":"idle","muted":false,"microphone":{"state":"on"},"jobs":["job-1"],"dev_fakes":false,
 "implementations":{"platform":"linux","stt":"whisper-local","vad":"sherpa","wake":"sherpa","tts":"persona","llm":"claude","worker":"claude-code"},
 "socket":"/run/user/1000/footman.sock","config":"/home/me/.config/footman/config.toml"}
```

`state` is the pipeline state (see `pipeline.state` below). `muted` is true after a stop. `microphone.state` is what the microphone loop is doing: `on`; `muted` (after a stop); `off` (not started, because there is no VAD); or `stopped`, in which case `microphone.error` says why it stopped (for example a hotkey registration failure, or a microphone that went away). An empty implementation name means that area is not available.

### `events.subscribe`

Params: `{"topics": ["pipeline.state", "jobs.*"], "buffer": 256}`, both optional. A topic is a name, a prefix ending in `.*`, or `*`; no topics means all. `buffer` is how many events may wait for this client before newer ones are dropped. Result: `{"subscription": "sub-1"}`.

Events then arrive as notifications:

```json
{"jsonrpc":"2.0","method":"event","params":{"subscription":"sub-1","topic":"pipeline.state","seq":12,"at":"2026-11-25T09:00:01.5Z","data":{"from":"idle","to":"routing","turn":1}}}
```

`seq` increases across all topics in the daemon; a gap means events were missed (a slow client) or belong to topics you didn't subscribe to.

### `events.unsubscribe`

Params: `{"subscription": "sub-1"}`. Result: `{}`. Subscriptions also end with the connection.

### `say.text`

Params: `{"text": "open youtube", "as": "command"}`. `as` is `command` (default), `dictate` (insert the text at the cursor, with cleanup) or `wake` (as if spoken after the wake word: "stop everything" is then the break-glass stop). Returns `{}` once the pipeline is idle again; background jobs it started keep running. Fails with -32001 while another utterance is being handled, and with -32000 if a stop cancels it.

### `jobs.list`

No params. Result: `{"jobs": [{"id": "job-1", "status": "running"}]}`, the jobs that have not finished. Statuses: `queued`, `running`, `succeeded`, `failed`, `cancelled`.

### `jobs.cancel`

Params: `{"id": "job-1"}`. Result: `{}`. Watch `jobs.update` for the final status.

### `config.get`

Params: `{"key": "dictation.insert"}` returns `{"key": "dictation.insert", "value": "auto"}`. Without a key, returns `{"values": {"dictation.insert": "auto", ...}}` with every set value. Secrets appear only as references (`"keychain:claude"`).

### `config.set`

Params: `{"key": "dictation.insert", "value": "paste"}`. The value must have the key's type (see `config.schema`). The config file is edited in place, keeping comments. Result: `{"key": "...", "value": ..., "reload": "live"}`; `"restart"` means the daemon must be restarted for the change to take effect. Invalid keys or values fail with -32602.

### `config.schema`

No params. Result: `{"keys": [{"path": "dictation.insert", "type": "string", "default": "auto", "description": "...", "enum": ["auto","type","paste"], "voice_settable": true, "reload": "live", "security_sensitive": false}, ...]}`.

### `system.stop_everything`

The break-glass stop (ADR-0017): cancels every job and in-flight request (and any speech) and mutes the microphone. No params. Result: `{"jobs": ["job-1"], "turns": 1}`, what was cancelled.

## Event topics

| Topic | `data` |
|---|---|
| `pipeline.state` | `{"from", "to", "turn"}`. States: `idle`, `listening`, `transcribing`, `routing`, `cleaning`, `inserting`, `acknowledging`, `fast_path`, `thinking`, `running_tool`, `replying`. `turn` numbers the utterance (0 when none). |
| `pipeline.transcript` | `{"turn", "trigger", "text"}`; trigger is `wake`, `dictate` or `command` |
| `pipeline.route` | `{"turn", "route", "text"}`; route is `dictation`, `command` or `none` |
| `pipeline.inserted` | `{"turn", "text", "method"}`; method is `type` or `paste` |
| `pipeline.fast_path` | `{"turn", "rule", "error"?}` |
| `pipeline.tool` | `{"turn", "name", "args", "result", "is_error"}` |
| `pipeline.reply` | `{"turn", "text"}` |
| `pipeline.error` | `{"turn", "state", "error"}` |
| `pipeline.stop` | `{"source", "jobs", "turns"}`; source is `voice`, `hotkey` or `call` |
| `pipeline.mic` | `{"mic"}`: `off`, `wake_listening` or `recording` |
| `jobs.update` | `{"id", "prompt", "status", "message", "at"}` |
