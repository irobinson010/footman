# Voice creation

This section is for people who want to make their own persona voices. Building a voice needs the **optional** voice kit. Nothing voice-training related is installed unless you ask for it, so users who only dictate never see this part.

## Coming soon

- Voice kit: what it installs, and how to add it on purpose
- Sourcing a voice: a voice description, a Troupe or Resonance Lab voice, or your own recordings with consent
- Building a dataset: a balanced script and the speech generated from it
- Training and evaluating: fine-tuning the small model, then blind listening tests and speed checks
- Packaging a persona: `persona.toml`, the generated clips, and `footman persona install`

For the workflow in brief, see [docs/design.md](../design.md) §27 (persona packs and the voice-creation workflow).
